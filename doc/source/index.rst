rpm-build-assist Documentation
================================

**rpm-build-assist** is a Python tool to build RPM packages using mock with
SCM (Source Code Management) integration. This tool simplifies building
multiple related packages from source control repositories and optionally
installing them into various targets like containers, flatpaks, or software
collections.
